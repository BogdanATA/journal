## Phase Goal

**As a** person who wants to write daily without ceremony, **I want to** open the app to a blank page for today and have every word I type land safely in a plain Markdown file I own, **so that** I can trust the app with my thinking without ever pressing save.

<objective>
Stand up the Walking Skeleton for Journal: install the missing Rust toolchain, scaffold the Tauri v2 + React 19 + TypeScript app, settle the one-way journal-storage-location decision, and prove the full stack end-to-end with a single vertical slice — launch to today's blank canvas, type, and have the buffer land in `YYYY-MM-DD.md` on disk and reload on relaunch.

Purpose: this is the architectural backbone every later slice (calendar navigation, tag pills, tag search) builds on. Proving the webview to Rust-core to filesystem path works on one real day file, with the correct capability scope, retires the two highest-risk unknowns in the project (Tauri's two-layer permission model and durable autosave) before any breadth is added.

Output: a runnable `npm run tauri dev` app with a dark-only canvas that autosaves today's writing to a plain Markdown file, plus `SKELETON.md`'s architectural contract made real in code.
</objective>
